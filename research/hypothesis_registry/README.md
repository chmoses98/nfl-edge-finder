# Hypothesis registry

One JSON file per hypothesis in this directory (`H-YYYYMMDD-NNN.json`). Fields: id, date_proposed, rationale, features, target, expected_direction, test_plan, dataset, result, oos_result, status (PROPOSED | TESTING | REJECTED | PROMISING | PROSPECTIVE_REQUIRED | VALIDATED), notes. Results are appended, never rewritten; a changed test plan is a new hypothesis id.
`registry.md` is the human index and is regenerated by `python scripts/research/registry_index.py`.
