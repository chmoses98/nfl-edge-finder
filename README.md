# nfl-edge-finder

Free-data NFL analytics, projection, and Kalshi market-pricing research platform for game lines, totals, player props, calibration, and edge research.

**Status: RESEARCH. Nothing here is validated for real-money use. Automatic trade execution is not authorized and not implemented.**

See `docs/` for the data-source audit, Kalshi market taxonomy, architecture and roadmap. Market observations live on the orphan branch `market-data`, never on `main`.
