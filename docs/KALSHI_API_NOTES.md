# Kalshi Trade API v2 — operational notes (verified 2026-09-04 from GitHub Actions)

* Base URL `https://api.elections.kalshi.com/trade-api/v2`. Public GETs need no auth. `nfl_edge/kalshi/client.py` sends only `Accept` + `User-Agent`, throttles at 4–5 req/s, backs off on 429/5xx, and returns `(items, complete)` from pagination so a failed page is never mistaken for an empty universe.
* `GET /series?limit=1000` returns the entire catalogue in **one page** (13,794 series); `include_product_metadata=true` adds `tags`, `product_metadata.scope`, `fee_type`, `fee_multiplier`, `settlement_sources`, `contract_url`.
* `GET /markets?series_ticker=S&status=open|unopened|closed|settled&limit=1000` paginates by `cursor`. Live tier only holds markets settled after the historical cutoff.
* `GET /historical/cutoff` → `market_settled_ts`, `trades_created_ts` (both 2026-07-05T00:00:00Z on audit day). `GET /historical/markets?series_ticker=S&limit=1000` paginates the archive (KXNFLGAME: 666 archived markets in one page; KXNFLSPREAD/KXNFLTOTAL > 3,000 each). `GET /historical/markets/{t}` and `/historical/markets/{t}/candlesticks` 404 for markets that are still in the live tier.
* `GET /markets/{t}/orderbook?depth=N` → `{"orderbook_fp": {"yes_dollars": [[price, size], ...], "no_dollars": [...]}}`. Prices are dollar strings with 4 decimals; sizes are fractional-contract strings.
* `GET /markets/trades?ticker=T&min_ts=&max_ts=&limit=1000` (global tape when `ticker` omitted) → `trade_id, ticker, count_fp, yes_price_dollars, no_price_dollars, taker_side, taker_book_side, taker_outcome_side, is_block_trade, created_time`.
* `GET /series/{S}/markets/{T}/candlesticks?start_ts&end_ts&period_interval=1|60|1440` → per candle `end_period_ts`, `price{open,high,low,close,mean,previous}_dollars`, `yes_bid{…}`, `yes_ask{…}`, `volume_fp`, `open_interest_fp`. A 7-day 60-minute and a 24h 1-minute request both succeeded.
* Market record fields (all present on every market): `ticker, event_ticker, market_type(binary), title, subtitle/yes_sub_title/no_sub_title, open_time, close_time, expected_expiration_time, expiration_time, latest_expiration_time, status (active|finalized|...), result (yes|no|"" ), expiration_value, settlement_value_dollars, settlement_ts, yes_bid_dollars, yes_ask_dollars, no_bid_dollars, no_ask_dollars, last_price_dollars, previous_*_dollars, yes_bid_size_fp, yes_ask_size_fp, volume_fp, volume_24h_fp, open_interest_fp, liquidity_dollars, notional_value_dollars, strike_type (greater|greater_or_equal|structured|custom), floor_strike, cap_strike, custom_strike{football_team, football_player, "Winning Margin", ...}, rules_primary, rules_secondary, early_close_condition, can_close_early, price_level_structure (linear_cent), occurrence_datetime, created_time, updated_time`.
* Event record: `event_ticker, series_ticker, title, sub_title ("NYG vs LAR (Sep 21)"), mutually_exclusive, product_metadata{competition:"Pro Football", competition_scope}, settlement_sources`.
* Series detail: `fee_type` is `quadratic_with_maker_fees` for KXNFLGAME/SPREAD/TOTAL/ANYTD/2TD/FIRSTTD/awards/division/conference/KXSB and `quadratic` elsewhere; `fee_multiplier` = 1 everywhere. Fee formula (documented schedule, not byte-verified here): taker `ceil(0.07 · C · P · (1−P))`, maker `ceil(0.0175 · C · P · (1−P))` on maker-fee series; no settlement fee.
* Important settlement rule on player-prop series (`product_metadata.important_info`): *"If a player is active but never takes a snap, the market settles to a fair price before game start. Once a player takes at least one snap, the market settles based on yards recorded."* Inactive players ⇒ fair-price settlement, not NO.
* Rate limits: 2,649 requests at 4 rps → 0 × 429. Documented Basic tier ≈ 20 reads/s. Capture runs at 5 rps.
